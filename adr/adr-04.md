# adr-04 Navigation

## Status

Accepted

## Context

A bottom tab bar with three tabs, one per feature, using Expo Router.

## Decision

We will be using Expo Router for this project, we have been working with expo router for majority of the semester.

## Consequences

### Positive

Expo Router provies a clean route grouping, supporting any folder that is parenthesized. It also automatically maps file routes to URIs.

### Negative

It is very strict when it comes to file structure, the directory must be in an exact Next.js format
